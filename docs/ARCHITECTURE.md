# 架構與維護邊界

## 目前的正式入口

| 入口 | 用途 | 維護規則 |
| --- | --- | --- |
| `index.html` | 品牌網站、建案內容、仲介流程與建商只讀銷售視圖 | 建商專區只顯示銷售狀態，不能進行管理操作。 |
| `yc-console-8k3n7q.html` | 管理員後台 | 管理員專用；包含建案、戶況、仲介與報備操作。 |
| `install.html` | PWA 安裝說明 | 僅處理安裝與裝置導引。 |

首頁的「建商專區」保留在只讀銷售視圖；頁尾管理入口則直接開啟獨立管理頁。兩者的權限與工作範圍必須維持分離。

## 漸進式重構策略

`index.html` 仍保留舊的內嵌管理與建商程式碼，以避免在未完成互動驗證前進行高風險的大量刪除。它們已不再由公開入口觸及。

下一階段應在確認新入口行為後，將舊區塊依序移除，並把可共用的前端邏輯抽到 `assets/js/`。不要用一次性腳本重新改寫 HTML。

## 非正式資產

- `archive/broker.html`：歷史仲介後台，不是線上入口。
- `photo/unused/`：未使用的圖片來源。
- `scripts/`：歷史就地修補腳本，詳見 `docs/DEVELOPMENT.md`。
